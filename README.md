# Hi, I'm Felix 👋

I enjoy figuring out how networks and infrastructure work — not just installing things, but understanding what happens when they don't behave as expected.

My background is in electronic security systems. In my spare time, I build and maintain **BiXCore**, a home network and security lab where I can learn by doing, troubleshoot real problems and document what I've learned.

### What I'm working with

- **Networks and security:** OPNsense, VLANs, IPv4/IPv6, WireGuard, Suricata and Zenarmor
- **Identity and certificates:** Windows Server, Active Directory, AD CS, FreeRADIUS, EAP-TLS and SCEP
- **Infrastructure:** managed switches, enterprise Wi-Fi, Linux, NAS services and Docker
- **Virtualization:** Proxmox and hands-on tests with different firewall and router platforms

I'm especially interested in understanding why something works, what fails under different conditions and how to make the setup more reliable. There's still plenty on my list to explore.
